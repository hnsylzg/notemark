# NoteMark 右键菜单规范

## 1. 目标

编辑器内所有右键菜单必须来自同一套上下文解析、菜单构建、定位和关闭逻辑。

禁止为零散元素分别实现菜单。新增元素或命令时，只增加：

- 上下文识别规则；
- 菜单项声明；
- 命令执行函数；
- 对应测试。

菜单 DOM、定位、主题、键盘、关闭行为不得复制。

## 2. 唯一入口

### 2.1 上下文解析

所有 `contextmenu` 最终交给同一个 `resolveMenuContext(target, event)`。

它返回：

```ts
interface MenuContext {
  kind: ContextKind;
  target: Element;
  editable: boolean;
  pmView?: EditorView;
  pmPos?: number;
  node?: PMNode;
  selectedText?: string;
  codeView?: CodeMirrorView;
  mathElement?: HTMLElement;
}
```

`ContextKind` 至少包含：

```text
table-cell
code-block
math-block
diagram
html-block
frontmatter
toc
list-item
task-item
quote
alert
heading
paragraph
readonly
```

### 2.2 判定优先级

从最高到最低：

1. NoteMark 自身菜单和浮层
2. 表格单元格
3. 代码块
4. 块级公式
5. 块级 HTML
6. Front Matter
7. 目录
8. 任务列表项
9. 普通列表项
10. 引用 / Alert
11. 标题
12. 普通段落
14. 只读或未识别区域

命中高层上下文后，不得继续执行低层菜单。

### 2.3 编辑区域

CodeMirror、MathJax SVG、textarea 等内部 DOM 不是“外部区域”。

它们只是元素自己的编辑实现。右键事件必须先由统一入口解析为：

- `code-block`
- `math-block`
- `math-inline`
- `html-block`
- `frontmatter`

不能因为事件目标位于 `.cm-editor` 或 `mjx-container` 内而直接放行给浏览器。

## 3. 统一菜单结构

菜单从上到下固定为以下分区，空分区自动移除：

### 上下文槽位

菜单中的“段落 / 表格 / 代码块 / 公式 / 图片 …”是同一个上下文槽位。
正文在该位置显示“段落”，其他块级元素只替换槽位的名称和内容；槽位
前后的公共菜单结构、顺序不得改变。所有行内组件都不建立独立子菜单，
统一使用所在文字块的标准菜单；“复制 / 粘贴为…”仍可按内容提供格式选项。

除表格外，可保留内容的块级组件都提供“段落”转换。只有内容为非空
单行时才同时提供 H1–H6；多行组件不能显示标题转换项。

### A. 快速编辑区

用于当前上下文直接可执行的高频操作，采用图标网格。

- 剪切
- 复制
- 粘贴
- 删除

不可用项保留并禁用，确保位置稳定。

### B. 对象操作区

当前对象自己的命令，例如：

- 编辑公式
- 复制代码
- 复制公式图片
- 替换图片
- 编辑 HTML
- 重建目录

使用文字行，不混入快速编辑网格。

### C. 特殊操作区

资源替换、内容替换或元素专属的不可逆操作。

例如：

- 替换图片
- 用剪贴板内容替换代码
- 用剪贴板 TeX 替换公式
- 用剪贴板 HTML 替换 HTML 块
- 切换 Alert 类型

### D. 转换区

适用于当前块的格式转换，例如：

- 段落 / 标题 1–6
- 有序列表 / 无序列表 / 任务列表
- 引用 / Alert 类型
- 左对齐 / 居中 / 右对齐

### E. 复制 / 粘贴为

只在当前上下文适用时出现：

- 复制到 Word
- 复制为 MathML
- 复制为 TeX
- 复制为图片
- 复制为纯文本
- 复制为 HTML 代码
- 粘贴为纯文本

所有右键菜单都不提供“全选”；全选只使用编辑器原生快捷键。

### F. 插入区

只用于正文或可插入块的位置：

- 图像
- 脚注
- 水平分割线
- 表格
- 代码块
- 公式块
- 内容目录
- YAML Front Matter
- 段前 / 段后段落

### G. 危险操作区

始终位于最底部，并在前面加分隔线：

- 删除选中内容
- 删除当前对象
- 删除整张表格

危险项使用统一 danger 样式，不使用零散表情图标。

## 4. 菜单项规范

每个菜单项必须声明：

```ts
interface MenuAction {
  id: string;
  label: string;
  group: MenuGroup;
  icon?: LucideIcon;
  shortcut?: string;
  contexts: ContextKind[];
  when?: (ctx: MenuContext) => boolean;
  disabled?: (ctx: MenuContext) => boolean;
  run: (ctx: MenuContext) => void | Promise<void>;
}
```

规则：

- `label` 使用明确动作，不使用“确定”“处理”等模糊词。
- 同一命令在所有元素中使用相同文案和图标。
- 通用快捷键只在真实支持时显示。
- 高频通用项可禁用；上下文专属项不适用时直接隐藏。
- 文案、图标和命令不得在多个模块重复定义。
- 不允许使用 emoji 代替界面图标。
- 不允许用非对称 padding、绝对定位补偿菜单对齐。

### 5.1 特殊替换与“复制 / 粘贴为”

每个元素必须声明两项能力：

```ts
interface ClipboardCapabilities {
  copyAs: ClipboardFormat[];
  pasteAs: ClipboardFormat[];
  replaceWith: ReplaceSource[];
}
```

“复制 / 粘贴为”是同一个全局子菜单，不同元素只决定其中出现哪些选项。

组件专属的复制/粘贴项只能追加在该子菜单中，不能替换全局项。所有上下文
都保留“复制为纯文本”“复制为 HTML 代码”“粘贴为纯文本”。

组件专属项不得和全局项重复。若组件源码也是纯文本，只保留全局
“复制为纯文本”；只有选区、整段代码、公式格式、图片等不同作用域或不同
格式时才新增专属项。

禁止为图片、公式、代码块分别创建独立的“复制为”菜单。

| 元素 | 复制为 | 粘贴为 | 特殊替换 |
| --- | --- | --- | --- |
| 普通文字 | 纯文本、Markdown、HTML 代码、Word | 纯文本、Markdown、HTML | 用剪贴板文字替换选区 |
| 链接 | 链接文字、链接地址、Markdown、HTML | 粘贴为链接地址 | 替换链接地址 |
| 行内公式 | Word、MathML、TeX | TeX | 用剪贴板 TeX 替换当前公式 |
| 块级公式 | Word、MathML、TeX、PNG | TeX | 用剪贴板 TeX 替换当前公式 |
| 代码块 | 选中代码、整段代码、Markdown 代码块、纯文本 | 在代码光标处粘贴纯文本 | 用剪贴板文本替换选区或整段代码 |
| 表格 | 单元格文本、选中表格、Markdown 表格、HTML 表格 | 纯文本、Markdown 单元格内容 | 替换单元格内容 |
| 图片 | 图片、图片地址、Markdown、HTML | 图片地址、本地图片文件 | 替换图片文件或图片地址 |
| 块级 HTML | HTML 源码、渲染文本、Markdown | HTML 源码、纯文本 | 用剪贴板 HTML 替换 |
| Front Matter | YAML 源码、纯文本 | YAML 源码 | 替换整个 Front Matter |
| 目录 | 目录 Markdown、纯文本、HTML | — | 重建目录 |
| 脚注 | 标记、Markdown、纯文本 | — | 替换脚注编号 |
| 水平线 | Markdown、HTML | — | 替换为剪贴板 Markdown |
| 只读区域 | 当前可读取格式 | — | — |

#### “复制 / 粘贴为”子菜单规则

- 子菜单名称统一为“复制 / 粘贴为…”。
- 先列复制格式，再列粘贴格式，中间使用分隔线。
- 没有可用项目时整个子菜单隐藏。
- 格式名称在所有元素中使用统一术语。
- 剪贴板 MIME 与菜单文案分离，菜单不直接暴露 `text/html`、`image/png` 等技术名称。
- 粘贴替代当前对象时必须归入“特殊操作”，不能混入普通粘贴。

#### 特殊替换规则

- 替换动作必须写明作用范围：选区、当前对象或整块。
- 破坏性替换先保留撤销事务，不直接修改 DOM。
- 图片替换先验证文件格式和可读取性，再写入模型。
- 代码、公式、HTML、Front Matter 替换必须走各自 schema 的提交入口。
- 替换失败时保留原对象，不清空内容。

## 6. 元素特性与差异化行为

所有元素共享同一套标准菜单骨架。元素只定制上下文槽位、快捷操作目标
和可用状态；不适用的公共动作保留并禁用，不能因此隐藏整套标准菜单。

菜单项目由元素能力决定，不能用一套固定菜单套到所有元素。

### 6.1 通用能力模型

| 能力 | 含义 | 菜单影响 |
| --- | --- | --- |
| `text-selection` | 使用 ProseMirror 文本选区 | 显示正文剪切、复制、粘贴和格式转换 |
| `code-selection` | 使用 CodeMirror 代码选区 | 编辑命令作用于代码文本，不作用于外层 Markdown |
| `node-object` | 当前右键目标是原子节点 | 先选中节点，再显示对象操作 |
| `structural` | 当前元素拥有行列、层级或父子结构 | 命令作用于当前单元格、列表项或容器 |
| `navigation` | 元素主要提供跳转或引用 | 优先提供打开、跳转、复制地址，不提供正文格式 |
| `readonly` | 元素不直接编辑 | 只允许复制、查看或安全的导航操作 |

一个元素可以有多个能力。例如链接同时具有 `text-selection` 和 `navigation`。

### 6.2 右键作用域

每个元素必须明确“右键命令作用于什么”：

| 元素族 | 作用域 |
| --- | --- |
| 正文 | 当前文字块或已有文字选区 |
| 列表 / 引用 / Alert | 当前列表项、引用项或 Alert 容器 |
| 代码块 | CodeMirror 当前选区；无选区时为代码光标 |
| 公式 | 当前公式节点及最新 TeX 源码 |
| 表格 | 当前单元格及其所在行列 |
| 图片 / 图表 / HTML | 当前原子对象 |
| 链接 | 当前行内标记，同时保留所在段落的文字能力 |
| 脚注 | 使用所在段落的菜单，不建立独立上下文 |
| Front Matter / 目录 | 整个对象容器 |

作用域不得跨越元素边界。

例如：代码块右键不能修改外层段落格式；表格右键不能删除相邻普通段落。

### 6.3 选区规则

所有元素统一遵循：

1. 右键落在已有选区内，保留原选区。
2. 右键落在选区外，把编辑位置移动到右键位置。
3. 原子对象没有文本选区，右键后先选中该对象。
4. 代码块使用 CodeMirror 的选区，不使用 ProseMirror 的选区。
5. 表格使用当前单元格和表格选区矩形。
6. 公式编辑态优先使用输入框中的最新源码。

### 6.4 正文流元素

#### 普通段落

- 作用域：当前段落。
- 快速编辑：剪切、复制、粘贴、删除。
- 转换：标题、列表、引用、强调、行内代码、行内公式、链接。
- 插入：完整正文插入菜单。
- 焦点恢复：原选区；无选区时回到右键位置。

#### 标题

- 显示当前标题级别为激活状态。
- 普通文字块显示“段落”和 H1–H6。
- 当前块已经是标题时，子菜单标题直接显示当前级别，例如“二级标题”，
  且不再显示“段落”项。
- 不以新增菜单层级代替修改标题级别。
- 空标题块仍可转换为其他标题级别。

#### 列表与任务列表

- 快速编辑作用于列表项正文。
- 列表右键作用域限于当前列表项及其子列表。
- 对象操作提供增加缩进、减少缩进。
- 任务列表在右键落在勾选标记时，提供“切换勾选状态”。
- 转换为标题或段落时只转换当前列表项内容，不隐式转换兄弟项。

#### 引用与 Alert

- `[!TYPE]` 标记本身按独立段落处理，子菜单中的“段落”项显示为已选中。
- 选择 H1–H6 时只把 `[!TYPE]` 标记段转换为标题，不并入 Alert 正文。
- 转换后保留外层 blockquote；是否继续识别为 Alert 由首段是否仍为标记段决定。
- Alert 正文中的每个内容段也是普通段落，使用标准文字菜单，可独立转换为标题。
- 自定义标题和正文继续保持独立段落，并与标记标题位于同一个 blockquote 中。

#### 链接与脚注

- 保留正文快速编辑能力。
- 链接和脚注引用都不提供特殊菜单，直接使用所在文字块的标准菜单。

### 6.5 内嵌编辑器元素

#### 代码块

- 代码选区来自 CodeMirror。
- 快速编辑只对代码文本生效。
- “复制整段代码”复制完整代码，不受代码选区影响。
- 对象操作：选择语言、编辑语言、自动缩进整段。
- 块转换只提供“段落”，不显示 H1–H6。
- 所有菜单都不提供“全选”；复制使用标准菜单入口。
- 全局“复制为纯文本”复制代码选区；全局“粘贴为纯文本”粘贴到代码选区。
- 不显示正文标题、列表、引用等转换项。
- 代码块未初始化时仍提供复制整段代码。
- 执行菜单命令后焦点回到 CodeMirror 原位置。

#### 行内公式

- 不提供独立“公式”子菜单，统一使用所在文字块的标准菜单。
- “复制 / 粘贴为…”中保留 Word、MathML、TeX 公式复制项。
- 不提供“复制为图片”。

#### 块级公式

- 与行内公式共享源码和复制格式。
- 额外提供“复制为图片”。
- 对象操作可包含居中、左对齐和右对齐。
- 不显示正文格式转换。

#### 块级 HTML

- 预览态：对象操作包含编辑 HTML、复制 HTML、复制纯文本。
- 编辑态：快速编辑作用于 HTML 源码 textarea。
- 不把 HTML 源码交给正文 Markdown 转换。

#### Front Matter

- 作用域为整个 YAML 容器。
- 提供编辑源码、复制源码、删除 Front Matter。
- 复制 YAML 源码时必须包含完整的 `---` 开头和结尾标记。
- “复制为纯文本”在整个 Front Matter 上下文中复制同一份完整源码。
- 不显示标题、列表、引用和正文插入菜单。

### 6.6 原子对象

#### 图片

- 图片作为行内内容，不提供独立菜单。
- 右键图片时使用所在文字块的标准菜单。

#### 代码块（Mermaid）

- Mermaid 按代码块上下文处理，不归入普通图表对象。
- 快捷复制复制 Mermaid 源码，而不是渲染后的图片。
- 代码块和 Mermaid 的组件子菜单只提供“段落”，不显示全选、复制或 H1–H6。
- 不显示正文格式转换。

#### 水平线

- 不显示剪切、复制选区等文字操作。
- 提供复制 Markdown、删除、段前 / 段后插入段落。

#### 目录

- 右键作用域为整个目录节点。
- 提供重建目录、复制 Markdown、复制纯文本。
- 块转换只提供“段落”，不显示 H1–H6。
- 删除目录必须删除整个目录节点，不能只删除当前文字。

### 6.7 结构化元素

#### 表格

表格使用统一菜单外壳，但内容按结构生成。

固定顺序：

1. 单元格快速编辑
2. 在上方 / 下方插入行
3. 在左侧 / 右侧插入列
4. 左对齐 / 居中 / 右对齐
5. 删除行 / 删除列 / 删除表格

规则：

- 行列命令只作用于当前单元格所在行列。
- 对齐命令修改整列，包括表头。
- 表格选区跨越多个单元格时，危险操作应明确提示影响范围。
- 表格菜单不能再维护独立的 DOM、定位和关闭实现。

### 6.8 焦点恢复

| 元素 | 菜单关闭后的焦点 |
| --- | --- |
| 正文 / 标题 / 列表 / 引用 | ProseMirror 原选区或右键位置 |
| 代码块 | CodeMirror 原选区或点击位置 |
| 公式 | 公式节点；选择编辑时进入源码输入框 |
| 表格 | 当前单元格 |
| 原子对象 | 所属 ProseMirror 节点 |
| 链接 | 原行内位置 |
| 脚注 | 所在文字块的原位置 |
| 只读区域 | 原只读容器，不抢正文光标 |

## 7. 各元素关键规则

### 7.1 文本类

段落、标题、列表、引用共用同一套正文菜单。

右键位置决定目标块。右键优先保留已有选区：

- 右键落在选区内：保持选区；
- 右键落在选区外：光标移到右键位置；
- 不得先让 ProseMirror 原生处理改变目标再打开菜单。

### 7.2 代码块

CodeMirror 选区是快速编辑操作的作用域。

- 右键落在选区内：保留代码选区；
- 右键落在选区外：光标移到右键位置；
- “复制整段代码”始终复制完整代码；
- 代码块未初始化时仍提供“复制代码”；
- 代码块菜单必须由统一菜单渲染器生成。

### 7.3 公式

行内公式与块级公式共享 Word、MathML、TeX。

“复制为图片”只在块级公式显示。

公式编辑态下优先读取输入框中的最新 TeX。

### 7.4 表格

表格不再维护独立菜单模块。

表格上下文向统一菜单提供：

- 当前单元格位置；
- 当前选区矩形；
- 当前行、列索引；
- 可执行的行列命令。

表格组固定顺序：

1. 快速编辑
2. 插入行
3. 插入列
4. 对齐
5. 危险删除

### 7.5 对象块

图片、HTML、Front Matter、目录使用对象菜单；Mermaid 使用代码块菜单。

对象菜单保留正文格式转换项，但将其禁用，不作为当前对象的操作。

对象右键后应先选中该对象，再执行对象命令。

## 8. 生命周期

所有菜单统一执行：

1. 解析上下文；
2. 捕获右键坐标和选区；
3. 阻止浏览器菜单；
4. 构建菜单；
5. 测量并限制在窗口内；
6. 监听外部点击、Esc、滚动、窗口尺寸变化；
7. 执行命令；
8. 关闭并清理事件；
9. 恢复合理焦点。

禁止各菜单模块自行维护第二套关闭和定位逻辑。

## 9. 键盘与无障碍

- `Escape` 关闭菜单，不冒泡到编辑器。
- 上下方向键在可用菜单项间移动。
- `Enter` / `Space` 执行当前项。
- 菜单根使用 `role="menu"`。
- 普通项使用 `role="menuitem"`。
- 分隔线使用 `role="separator"`。
- 图标按钮必须有 `aria-label` 和 `title`。
- 禁用项使用原生 `disabled`。
- 菜单打开后焦点进入菜单，关闭后回到原编辑位置。

## 10. 事件优先级

`contextmenu` 使用捕获阶段解析，避免 CodeMirror、MathJax 或浏览器内部组件抢先消费。

统一优先级：

1. NoteMark 菜单浮层
2. 表格单元格
3. 代码块
4. 公式
5. 其他对象块
6. 正文
7. 浏览器原生菜单

只有未被任何上下文识别的区域才允许浏览器原生菜单。

## 11. 代码组织

目标结构：

```text
src/editor/context-menu/
  resolver.ts       # DOM/ProseMirror/CodeMirror -> MenuContext
  registry.ts       # 所有菜单动作声明
  renderer.ts       # 唯一菜单 DOM 和分组渲染
  controller.ts     # 打开、定位、关闭、焦点、键盘
  commands.ts       # 动作执行函数
```

现有 `format-menu.ts` 和 `table-menu.ts` 的菜单构建逻辑最终迁移到上述结构。

迁移期间允许保留旧入口，但只能调用统一 renderer，不得继续复制菜单 DOM。

## 12. 迁移顺序

### 第一阶段：基础设施

- 抽出 `MenuContext` 和 `resolveMenuContext`
- 抽出唯一菜单 renderer/controller
- 统一菜单 CSS 和键盘行为

### 第二阶段：高频元素

- 普通段落与标题
- 列表与任务列表
- 引用与 Alert
- 代码块
- 行内 / 块级公式
- 表格

### 第三阶段：对象元素

- 图片
- Mermaid
- HTML
- Front Matter
- 目录
- 脚注与链接

### 第四阶段：一致性测试

- 每个元素只出现规定菜单项
- 分组顺序稳定
- 危险项位于底部
- 禁用条件正确
- CodeMirror / MathJax 内部右键不逃逸
- 窗口边缘自动回位
- 键盘导航和 Esc 正常
- 命令执行后焦点正确

## 13. 禁止事项

- 禁止为一个新元素新增独立菜单文件。
- 禁止复制 `mt-context-menu` 的构建逻辑。
- 禁止在元素内部直接调用 `event.preventDefault()` 后自行弹菜单。
- 禁止用元素专属 DOM 查询代替统一上下文解析。
- 禁止无规范地增加菜单项顺序。
- 禁止同时出现浏览器原生菜单和 NoteMark 菜单。
- 禁止用像素偏移补偿菜单布局。
